Feature: initialize counter on mount

What I changed
- `useButtonCounter` now performs `GET /api/v3/counter` on mount to initialize `count`.
- During initialization, `isLoading` is true until the GET completes.
- On GET failure, `error` is set to a clear message (`Failed to load counter`) and `count` remains at `0`.
- Existing `handleClick` POST behavior unchanged; tests updated to account for the initial GET call.

Why
- Ensure the UI shows the current counter value immediately when the component mounts and correctly indicates loading during initial fetch.

Testing
- Added/updated tests in `src/TheButton.Web/src/hooks/useButtonCounter.test.ts` to mock the initial GET and the subsequent POST calls, covering success, failure, and loading states.

Notes
- No API contract changes required.
- No deterministic idempotency keys used in tests; `crypto.randomUUID()` remains unmocked.
