# Skills

This file lists the available short commands and skills for the Antigravity AI agent.

## Short Commands (Workflows)
Accessible via `/[command]` (e.g., `/pr`)

- **pr**: Automates the branch creation, commit, and PR submission process.
  - File: `/.agent/workflows/pr.md`

## Skills
Specialized instructions for complex tasks.

- **pr**: Detailed instructions for the PR workflow.
  - Folder: `/.agent/skills/pr/`
- **backlog**: Detailed instructions for the backlog update rules.
  - Folder: `/.agent/skills/backlog/`
